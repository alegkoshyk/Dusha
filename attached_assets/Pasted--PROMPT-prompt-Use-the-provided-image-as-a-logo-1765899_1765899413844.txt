ЛАВНЫЙ PROMPT (база)

👉 Используй ЭТО как основной prompt в коде:

Use the provided image as a logo reference.

Generate a realistic branded merchandise mockup.
Place the logo naturally on the product.
Do not redraw, modify, or distort the logo.
Keep original proportions, colors, and shape.

Photorealistic product photography.
Studio lighting.
Clean minimal background.
High quality, commercial look.


⚠️ Важно: этот prompt всегда должен идти вместе с картинкой-логотипом.

4️⃣ NEGATIVE PROMPT (обязательно)
distorted logo, modified logo, wrong text, extra symbols, watermark, blurry, low quality, stretched logo

5️⃣ РЕКОМЕНДУЕМЫЕ ПАРАМЕТРЫ ДЛЯ API
{
  "strength": 0.25,
  "guidance_scale": 7,
  "num_outputs": 1
}


📌 Пояснение:

strength 0.2–0.35 → логотип сохраняется чётко

guidance_scale 6–8 → хорошо держит инструкцию

6️⃣ ПРИМЕР ЗАПРОСА (JS / Replit)
